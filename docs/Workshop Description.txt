[h1]THIS ADDON NEEDS A SEPARATE APPLICATION - IT DOES NOTHING ON ITS OWN[/h1]

[h2][b]Download the application:[/b] [url=https://github.com/DrStr4Nge147/Left-4-Dead-2-External-HUD/releases]Left 4 Dead 2 Customized Overlay HUD - External (GitHub releases)[/url][/h2]

This Workshop item is the exporter half. It writes live survivor state to a file; the separate application reads that file and draws the HUD. Both halves are required and must be v1.3.0.

[list]
[*][b]Standalone[/b] includes the required .NET components.
[*][b]Compact[/b] is smaller, but requires the [url=https://dotnet.microsoft.com/download/dotnet/9.0].NET 9 Desktop Runtime for Windows x64[/url]. Choose [b]Desktop Runtime[/b], not only the base .NET Runtime or ASP.NET Core Runtime.
[/list]

[h1]WHAT IT IS[/h1]

An external survivor HUD for oversized rosters. It shows every mortal survivor in the session, not only the four slots available in the built-in HUD. It is designed for [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3766326051]Finale Soldiers[/url] and other mods that spawn more than four survivors.

Cards show the survivor name, permanent health, temporary health from pills or adrenaline, black-and-white state, and incapacitated / hanging / dying / dead state. Cards show each survivor's carried items, except your own: your throwable, kit, and pills sit with your weapons and ammunition instead, where vanilla keeps them. The Tab scoreboard shows the whole team's, including yours.

The [b]Scoreboard[/b] view appears while [b]Tab[/b] is held. The [b]Consistent HUD[/b] view can stay visible during play and does not open the game's scoreboard. The application watches Tab without changing key binds.

[h1]REQUIREMENTS[/h1]

[list]
[*][b]Host the session.[/b] Single player or host a coop session. VScript is server-side, so the HUD has no data when joining someone else's server.
[*][b]Run L4D2 borderless windowed[/b] with [b]-windowed -noborder[/b]. External windows cannot draw over exclusive fullscreen.
[*]Windows only. Standalone needs no runtime; Compact needs the .NET 9 Desktop Runtime for Windows x64.
[/list]

[h1]HOW IT WORKS[/h1]

The overlay does not inject into the game, read memory, hook DirectX, change gameplay, or add server commands. The addon writes live state here and the application reads it:

[code]
left4dead2\ems\overlay_hud\state.json
[/code]

[h1]CUSTOMISING THE HUD[/h1]

Right-click the overlay's notification-area icon and choose [b]Customize UI...[/b], or hold [b]Tab[/b] and press [b]Insert[/b]. Changes are applied with [b]Save & Apply[/b]; [b]Cancel[/b] discards them.

[list]
[*][b]Scoreboard tab:[/b] controls the Tab-held panel beside the vanilla scoreboard, including position, size, opacity, columns, and guide lines.
[*][b]Consistent HUD tab:[/b] keeps a separate HUD visible during play and has its own size, opacity, vertical position, spacing, health-number, and theme controls.
[*][b]Templates:[/b] [b]Bottom - Horizontal Grid[/b] is the default; [b]Lower Left Vertical Grid[/b] and [b]Lower Right Vertical Grid[/b] place cards in vertical groups. The horizontal layout uses four cards across and up to three rows, adding columns for larger rosters.
[*][b]Designs:[/b] [b]Basic[/b] uses full cards. [b]Minimalist[/b] puts the name before the health value above a compact five-segment health strip, keeps temporary-health grunge, and clips long names.
[*][b]Separate You:[/b] moves the current survivor into an independent card. The bottom grid places the roster left and You right; the lower-right vertical grid places the roster right and You left. A visible group gap prevents overlap.
[*][b]Flexible presentation:[/b] health numbers can be hidden, the Consistent HUD can use a black-and-white theme, and horizontal / vertical spacing may be negative for intentional overlap. The top-right status badge stays fixed at 1.0x while the HUD is resized.
[*][b]Preview:[/b] use the live roster over L4D2 or a simulated roster when the game is closed. The editor can also ask the addon to hold the game's scoreboard open while positioning the external panel.
[/list]

[h1]WHO THE HUD SHOWS[/h1]

[b]Who to show[/b] provides four mutually exclusive filters:

[list]
[*][b]All survivors[/b] - every mortal survivor, including the four already shown by the vanilla HUD.
[*][b]Extra survivors[/b] - the previous All behavior: mortal soldiers, followers, and plain survivors from slot 5 onward.
[*][b]Mortal soldiers + followers[/b] - Finale Soldiers' mortal soldiers and followers only.
[*][b]Followers only[/b] - soldiers currently following a player.
[/list]

Immortal holdout soldiers are excluded in every mode because they cannot be hurt. Followers carry a blue [b]FOLLOW[/b] marker in the mixed roster modes.

[*]Keep the application and addon on the same version. The application reports a mismatch without blocking the HUD.
[/list]

[h1]IF NOTHING APPEARS[/h1]

[list]
[*]If Compact does not start, install the .NET 9 Desktop Runtime for Windows x64. Standalone includes its runtime.
[*]Check the top-right badge. It reports when the addon is missing, duplicated, disabled, or out of date.
[*]If there is no badge or HUD, use [b]-windowed -noborder[/b] and confirm the application is running.
[*]If the app is running but the panel is empty, confirm that the session is hosted and that the selected roster filter has survivors to show.
[*]Enable the application's [b]debug console[/b] for a readable log of the addon, state file, version, and errors.
[/list]

[h1]COMPATIBILITY[/h1]

Script only. The addon reads survivor state and writes one file; it changes no gameplay, entities, damage, Director behavior, or cvars. The application draws outside the game and does not conflict with HUD replacements.
